# Volt Academy

Cursos introdutórios de mecânica de carros elétricos em português do Brasil.

Inclui laboratório 3D autoral, 12 aulas, 4 apostilas e certificados de conclusão locais. O player do vídeo indicado utiliza o original do YouTube; o vídeo não foi baixado nem republicado.

Site estático. Publicação com GitHub Pages, branch main e pasta raiz. Progresso, respostas e registros de certificados ficam no navegador. Os certificados não são diplomas nem habilitação para alta tensão.
